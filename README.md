# WebAura Studio

Static agency website for Muhammad Ahmad Raza, with responsive service pages, a rule-based Growth Planner, contact links, and an embedded location map.

## Run locally
Open index.html in a browser. No package installation or build step is required.

## GitHub Pages
Publish the main branch from the repository root in Settings > Pages. Keep index.html, style.css, app.js, logo.png, and .nojekyll together at the root.

## Functionality
The Growth Planner uses transparent rules and exports a plain-text roadmap. The enquiry form opens the visitor's email app; it does not send or store submissions. WhatsApp and map links require internet access. Google Fonts and the embedded Google Map are external services.

## Editing
- index.html: content, contact details, and map
- style.css: design and responsive layouts
- app.js: planner, menu, and email form
- logo.png: studio logo

This repository intentionally excludes hosting credentials, deployment archives, and the original hosting provider configuration.
